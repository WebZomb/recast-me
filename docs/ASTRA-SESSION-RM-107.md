# RM107 — Better pet identity with already-improved Standard adventures

Date: 2026-10-10. User compared new Standard Holiday Magic and Rock Star against previous Standard results for the same pet. The **new** prompts successfully produce snow-covered Christmas scenes and real concert stages with costumes, but the pet's face and head anatomy drift somewhat more than in older results. The **older** images preserve more of the original face partly because they often left the original backyard/camera view intact; this association is observed, not causal proof.

## Narrow prompt-only modification
Baseline GitHub main before this branch: `749b6838eb78fdc7b588dce8948e0378b927854c`. Existing fal HQ FLUX.2 dev, Cloudflare Standard Klein-9B, models, steps, dimensions, budgets, private R2, watermarking, image consent, customer credits, order/Printful/Shopify logic, 48 distinct scene guides, UI, account handling and provider rules remain unchanged.

In `src/standard-adventure-prompt.js` change the instruction from “MAKE ONE NEW IMAGE” (which can invite replacing the **subject**) to “EDIT THE UPLOADED PHOTO(S) into a themed scene with the EXACT SAME SUBJECT(S).” Prepend a concise high-priority **identity anchor** ahead of the scene that explicitly preserves pet eye placement, ear size/tilt, muzzle, nose, natural facial expression, head direction and fur markings. Add subject-aware anchors for people, vehicles and mixed person-pet families. **Keep the strong early background-replacement directive and all existing 48 scene/wardrobe art guides unchanged.** Ask the editor to change the world/outfit around the original identity and avoid redrawing the face as a generic lookalike.

The existing longer identity rules still follow immediately after the adventure scene and outfit. This provides identity priority within the first ~400 characters while keeping the backdrop/wardrobe change in the model's early context (~600 characters), rather than reverting to the old excessively long identity-first prompt that frequently retained the original yard.

`src/highquality.js` updates metadata for Standard results only from `standard-adventure-scenes-v1` to `standard-identity-scenes-v2`; actual HQ image engine instructions and routing remain unchanged. Existing mocked integration and all-48 tests updated, plus regression that checks the real pet’s facial features are explicitly anchored BEFORE each of the 48 different settings without losing the set/costume details. This is not an identity-locking neural network or masked image compositing, and **cannot guarantee pixel-perfect likeness** on every generation.
