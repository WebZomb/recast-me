# Anonymous private browsing render-credit audit — Oct 9, 2026

The user's concern was that Safari Private Browsing could create another 3 free High Quality renders. **Do not alter the functioning customer site without demonstrating a bypass.** Review of production main `1330f0c466c3a4faeeb273763a36b91fb91aab48` showed that each visitor receives an HttpOnly cookie, but actual daily HQ trial and Standard counters are keyed to a PRIVATE, HMAC-hashed Cloudflare `cf-connecting-ip` network identity in R2 (`commerce/trials/<network>` and `commerce/standard/<network>`). The HMAC salt is persisted privately in R2 and is never returned to browsers. Therefore, *new private sessions on the same public IP should share the same daily allowance*, not receive additional trials. The cookie alone does not determine the quota.

This audit adds regression tests only: new cookie/same IP cannot restart HQ or Standard limits, successful renders debit the shared quota, failed attempts restore it, actual paid-order bonuses remain attached to the original wallet, network salt stays private, and a genuinely different IP is correctly recognized as a **remaining anonymous identity limitation**.

Privacy trade-offs: IP identity cannot reliably follow users across VPNs, iCloud Private Relay exit IP changes, mobile/Wi-Fi changes, and devices; carrier-grade NAT and a household or business sharing one IP may already share quotas. More aggressive IP-range blocking or stealth browser fingerprinting would risk harming genuine customers and privacy. Accurate per-person enforcement across browsers/networks requires a verified account, email/phone confirmation, or another persistent identity that the user must authorize. No code/config/credits/commerce/rendering/Cloudflare deployment changes were made in this audit. The tests do not prove that a changing-IP user cannot evade the anonymous quota.

Revert by closing the test-only PR; it has no runtime modifications. Do not promise complete circumvention prevention without a product decision about identification and legitimate shared-IP experience.
