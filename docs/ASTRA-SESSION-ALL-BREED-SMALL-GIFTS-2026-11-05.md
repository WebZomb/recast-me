# Remaining-breed small-gift expansion — November 5, 2026

## Owner request and verified starting point
The owner asked to continue finishing the ready-made shop after the Golden Retriever Christmas Village Coaster Set, Magnet Set and six-picture Sticker Sheet were digitally reviewed, published and tested through Shopify checkout. Baseline main is `e23a1d13d9eeb3f2e221f2ba37636bf91ba1f9f4`. A fresh read-only public catalog check returned 73 offers: 70 mug-size offers and one each coaster, magnet and sticker sheet. The 70 mug offers include the existing source catalog; this count is NOT a claim that all 35 expansion artworks are newly complete. No already-published Golden product is changed or republished by the new preparation queue.

## Implemented in the review branch
- `src/shop-gift-definitions.js` keeps the original three Golden IDs, SKUs, templates and R2 keys byte-for-byte. It derives 102 additional combinations from the remaining 34 pinned `EXPANSION_DESIGNS`: each source gets its own Coaster 4-Pack, Magnet 3-Pack and six-picture Sticker Sheet ID, title, request identity and native print file.
- `src/shop-gift-batch.js` prepares only those 102 new combinations. Each scheduled execution takes a compare-and-swap lease, creates at most two supplier mockup tasks under the EXISTING shared two-per-65-seconds provider limiter, polls at most four saved tasks and freezes at most two clean native files. Individual durable claims precede provider POSTs. Lost responses and uncertain states are held rather than blindly repeated. No queue action publishes a product, confirms a customer order, creates AI artwork or submits printing.
- Source approval requires exact original request ID, revision, catalog design ID, rights, content screening and a pre-existing verified supplier offer. Native areas remain 1181×1181 JPEG coasters, 900×900 JPEG magnets and 1750×2482 transparent PNG sticker sheets with six independently downscaled original pictures. Missing/unreviewed originals and changed templates are held; none are bypassed to fill a count.
- Native-file freezing now selects the correct registry source rather than a global Golden Retriever source. Its existing snapshot SHA, supplier task, placement, clean-file hash and immutable preapproval rules remain unchanged.
- Owner review supports `?design=<approved design ID>`, returning only the selected artwork and its three exact product slots. The native response boundary allows only the fixed 105 registry paths; existing Admin Bearer authentication precedes ANY private storage lookup, and file/source/SKU/proof checks remain mandatory. Customer/public images still go through the original watermark protection.
- The private review page adds a mobile-friendly breed selector, published/ready/held counts and a Next ready design button. Switching a breed clears and revokes the previous images. It never publishes automatically. A failed print file blocks only that product's publication rather than erasing other good review cards.
- The existing publication endpoint accepts individually reviewed registry IDs and exact signatures only. It still checks the live origin, Admin Bearer, bounded JSON, source revision, clean-file bytes, saved supplier views and current ACTIVE Shopify row. No bulk approve switch was added. Public catalog/checkout gains a new offer only after the explicit review acknowledgement and confirmation.

## Paid actions, limitations and rollback
No image-generation credits, customer payment or paid printing action is part of this code change. The intended production rollout generates bounded actual Printful mockups and native product files using existing configured services, not a new provider or subscription. Supplier rate limits apply. Existing keys and claims must never be deleted to force a retry. Physical sample quality, address-dependent delivery/taxes and a completed paid purchase are not verified by the automated tests.

Rollback preparation by setting `PREMADE_GIFT_BATCH_ENABLED=false` in the guarded deployment. Preserve all task/release records and any reviewed offers. Reverting registry/review support after additional products are published requires care: those products' native files and audit records must remain accessible for fulfillment and support. Blankets, apparel, canvas and other large products are outside this small-gift queue and still require appropriately detailed product masters and supplier proofs. Do not call the entire 17-category catalog complete.
