# RM055 new product proof pass

Generate supplier mockups only for the six existing Shopify products now mapped for purchase: Sticker, Phone Case, Pillow, Hardcover Journal, Puzzle, and Tote Bag. This pass uses the existing approved public Recast artwork, creates no checkout, order, draft order, or production submission, and requires exact variant identity and geometry before any sample can be accepted as a storefront example.
