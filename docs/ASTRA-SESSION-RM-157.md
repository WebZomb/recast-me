Both My Orders and private order-detail pages independently require shipment state and `trackingReady` before rendering links. Pending orders display a clear awaiting-shipment note; links with unknown tracking status fail closed. No new Printful API operations, order submissions, manual fulfillment, replacements, charges or refunds.

Dialog has a visible, tappable close button and reduced-motion controls. The real modal still triggers once only after verified payment; the interactive demo remains a **no-purchase, no-credit** sample.
