The main remaining buttons are Save/share preview, Save to My Recasts, and Open in another browser. - New `src/shipment-tracking.js` runs **after existing private token verification**. Authenticated `/api/order-status` responds with `trackingReady`, `trackingNumber`, `carrier`, and safely gated `trackingUrl`. Both My Orders and private order-detail pages independently require shipment state and `trackingReady` before rendering links. Pending orders display a clear awaiting-shipment note; links with unknown tracking status fail closed. No new Printful API operations, order submissions, manual fulfillment, replacements, charges or refunds.
- Both paid-return overlay and `/purchase-demo.html` use a much larger, high-contrast celebratory card, big gradient badge, stronger confetti and larger accessible CTAs. Dialog has a visible, tappable close button and reduced-motion controls. The real modal still triggers once only after verified payment; the interactive demo remains a **no-purchase, no-credit** sample.
