## Implemented

- Photo step shows `Include: Automatic · Change` after upload. Five primary choices: Automatic, Pet, People & pets, Person, Group of people; older couple/family/car/custom choices remain under More choices. No mandatory Who screen. Fresh uploads reset prior category hints.
- Optional face selection opens a native dialog with full original photo proportions. Tap faces to include, remove markers, or use keyboard arrows/Enter; at most eight markers across four reference photos. Selected locations become short image-relative instructions in the existing render request. No extra image-analysis request, detector, segmentation, face recognition database or paid classifier. Marker state is attached to original File objects and does not leak into replacement photos.
- Important limit: Automatic is truthful, not a fabricated pre-upload prediction. Recognition happens inside the image generation call. There is no automatic ambiguity detector or true protected-face mask. Face taps and category choices guide the model but cannot enforce pixel-exact identity or reliable removal.
- Explicit production setting `FAL_CUSTOMER_MODEL=nano-banana`: public fal High Quality now selects `fal-ai/nano-banana/edit`, keeps full-detail original references, one provider submission, strict queue destination checks, independent input/output screening, private original/artwork storage, budgets and watermarks. Original owner comparison routes retain their own explicit models. Standard remains Cloudflare Klein. Public Nano records actual model and `nano-identity-adventures-v1`; provider health updates remain active. Public model status, cost estimate and privacy disclosure updated.
- All 48 adventure scenes/outfits feed the shorter Nano identity prompt. Automatic does not blanket-remove supporting people; explicit category/face selections narrow inclusion. Prior artwork remains a continuity reference; original inputs define identity. No public generative face-mask/compositing service implemented.
- Product cards offer Preview on product and Buy now. Buy now is available for recommended settings only; custom placement requires a mockup or reset. Artwork review shows the selected watermarked picture, product/variant/price and layout, explains that the mockup is skipped, and requires explicit artwork approval before secure checkout.
- The fast server path validates artwork access, screening, active Shopify SKU, explicit consent, exact normalized recommended settings, supplier variant identity and print dimensions. It prepares the same production layout without creating a supplier mockup task, and freezes exact private source bytes, hash, layout and consent. The prepared record is NOT falsely marked as a completed mockup. The existing paid-order verification/preapproval/fulfillment pipeline consumes the snapshot. Proof pages label this as artwork approval with mockup skipped. Public proof images still cross the existing watermark boundary; clean snapshots remain private.
- Mockup timing starts at a conservative 1–2-minute estimate, not an observed production benchmark. After three successful previews in that browser session, a bounded rolling sample updates the displayed range. Failure/retry, stale artwork and custom-setting handling retained. Single-image review gets a legible full-width preview.
