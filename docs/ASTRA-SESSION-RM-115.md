# RM115 — Simple creator / original-photo first (October 10, 2026)

## User request and baseline
Owner showed five iPhone screenshots of the Recast creator: lengthy used-up credit notices and consent, hidden "Use my photo as-is · no AI" accordion at the bottom, many overlapping instructions and a distracting full list of adventure worlds. Specifically requested accessible, very easy navigation for older and internet-inexperienced customers with clear first actions and minimal reading.
GitHub baseline main \`e1394ec7e69f00eecf10320df42ac39531687dfa\`. Work branch \`recast/rm115-simplified-creator-20261010\`, PR pending at start.

## Actual code changes
- \`public/index.html\`: introduces two large, clearly labelled and visible buttons **Create a new picture (AI)** and **Use my original photo (No AI)** at the very start of the creation card, in logical tab order. Original-photo form stays exactly the existing vetted private storage/Turnstile and photo-consent path, now front-loaded when selected. Existing "open saved picture" link stays available but optional. Step 0, photos, and adventure instructions shortened. Only 4 favorite adventures visible by default; full select and descriptions remain available with "See all adventures" expand control; "Surprise me" stays visible. Optional special instructions stay in collapsed details.
- \`public/simple-creator-v115.js\`: moves **the same original-photo form node**, never duplicates it, from the hidden alternate accordion to the new immediate alternative panel; updates aria-pressed and shows/hides the AI wizard without deleting selected inputs. No new image request, commerce, provider, secret, or credits action.
- \`public/simple-creator-v115.css\`: high-contrast, 80–100px touch targets with visible teal original-photo card, checked state, readable copy and original-upload file control; one-column cards on phones, two-column on desktop, keyboard focus; compact credits and fallback.
- \`public/creation-wizard.js\`: short subject-specific photo hints, optional reveal of full adventure list while preserving its value, all 48 worlds, custom descriptions and surprise. Existing per-subject photo-label validations unchanged.
- \`public/quality-policy.js\`: retains all return values and server eligibility decisions (HQ-first free Standard, acquired Standard, actual outage, exhausted) but uses <=~160-character fallback notices; exposes read-only \`creditHeadline()\` for concise main balance while exact free/used/bonus/purchased/reset info remains behind an accessible collapsed "Credit balance & reset times" details panel. No account quota or allowance changes.
- \`public/app.js\`: calls \`creditHeadline()\` and existing \`creditSummary()\` for compact/expanded fields; simplifying button and operational status copy without changing render requests/AI models, Turnstile, charged operations, saved versions, or checkout.
- \`tests/quality-policy.test.mjs\`, \`tests/simplified-creator.test.mjs\`, \`scripts/rm050-browser-tests.cjs\`, \`tests/adventure-prompt-audit.test.mjs\`: validates minified copy, unchanged server feature semantics, real mocked browser clicking on both choice cards and advanced worlds with WebKit iPhone and Chromium desktop, protected original photo upload and exact credit reset accessibility. Browser tests do NOT actually submit a billable AI request or spend credits.
- No Shopify product edits, no shipping/print orders, no account/subscription/services added.
